image_tools pack: third-party notices

The plugin embeds no model or data file. It links these Rust crates, each under
a permissive licence (MIT, Apache-2.0 or both); run `cargo tree` in
plugins/image_tools for the full list.

image, png, jpeg-decoder, zune-jpeg, gif, tiff, image-webp
  Decoding and encoding of PNG, JPEG, GIF, BMP, TIFF and WebP.
  https://github.com/image-rs/image

fast_image_resize
  Convolution resampling, run on its portable code path.
  https://github.com/Cykooz/fast_image_resize

rxing
  QR code and barcode reading (a Rust port of ZXing, Apache-2.0).
  https://github.com/rxing-core/rxing

font8x8
  The 8x8 bitmap letters used for labels. The glyph data is the public domain
  font8x8 by Daniel Hepper (https://github.com/dhepper/font8x8); the crate is MIT.
  https://gitlab.com/saibatizoku/font8x8-rs

serde, serde_json, base64, sha2
  Request parsing, base64 and SHA-256.

Used only by the tests and the fixture generator, never linked into the plugin:
proptest, qrcode and jpeg-encoder.

The test fixtures are generated by plugins/image_tools/tools/gen_fixtures.rs
from fixed seeds; the ICC bytes in them are a synthetic blob, not a real colour
profile, and no third-party picture is included.
